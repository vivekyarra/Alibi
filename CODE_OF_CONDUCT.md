# Code of Conduct

GRIDPRINT adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

All contributors and maintainers are expected to follow it in issues, pull requests, and any other project space.

To report unacceptable behaviour, open a private report through the repository's
[GitHub security advisory form](https://github.com/vivekyarra/Alibi/security/advisories/new)
(mark it as a conduct report) rather than a public issue. Reports are handled confidentially.
